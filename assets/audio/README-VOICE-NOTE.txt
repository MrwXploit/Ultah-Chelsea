CARA MEMASUKKAN VOICE NOTE KE SURAT RAHASIA

1. Rekam pesan suaramu menggunakan Voice Recorder di HP atau laptop.
2. Simpan/ekspor rekaman dalam format MP3 dan beri nama persis: voice-note.mp3
3. Letakkan file tersebut di folder ini (assets/audio/). Path lengkapnya menjadi assets/audio/voice-note.mp3.
4. Jalankan ulang website atau refresh halaman, buka Surat Rahasia sampai isi surat selesai ditampilkan, lalu tekan Play pada pemutar audio.

Jika rekaman hanya tersedia dalam M4A atau WAV, file dapat digunakan dengan mengubah source di index.html pada elemen audio id="letter-audio". Ubah src ke nama file yang sebenarnya dan type menjadi audio/mp4 untuk M4A atau audio/wav untuk WAV.

Catatan: tidak ada file voice note bawaan di versi ZIP ini. Rekaman pribadi perlu ditambahkan sendiri.
